# 22 November 2026 World News

This repository contains a single PNG news summary for 22 November 2026.

## Entry

- `main.ts` copies `entry.png` to `/output/entry.png`
- `entry.png` is a 1024 x 1024 PNG
- `LICENSE` contains the MIT License

Run locally:

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```
