This repository contains a 1024 x 1024 PNG summarizing world news reported on 22 November 2026.

## Entry

- `main.ts` copies `entry.png` to `/output/entry.png`
- `entry.png` is the final news graphic
- `LICENSE` contains the MIT License

## Run

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```
